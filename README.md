# web-foundations-24330211024


* 1.YouTube
*  ** URL: https://www.youtube.com/
*  ** Method: GET
*  ** Situs Code: 200 OK
*  ** Content-Type: text/html; charset=utf-8

*  Request
* pesan atau instruksi digital yang dikirim oleh perangkat Anda (HP, komputer, atau TV) ke server YouTube untuk meminta data tertentu.

* Response dalam YouTube adalah jawaban atau tanggapan balik yang dikirimkan oleh server YouTube kepada aplikasi atau peramban (client) milik Anda setelah menerima HTTP Request


* 2. Lk21
* ** URL: https://tv12.lk21official.cc/
* ** Method: GET
* ** Status Code: 200 OK
* ** Content-Type: text/html; charset=UTF-8

* Request
* browser Anda ke server untuk memuat halaman, meminta potongan file video saat streaming, dan memicu pop-up iklan otomatis.

* Response
* HTTP Response di LK21 adalah balasan dari server ke browser Anda yang berisi data tampilan web, potongan file video saat streaming, pengalihan tab iklan otomatis, atau pemberitahuan error jika video diblokir.


* 3. Zoom
* ** URL: https://zoom.us/id/signin
* ** method: GET
* ** Status code: 200 OK
* ** content-type: text/html;charset=utf-8

* Request
* permintaan data atau perintah yang dikirimkan oleh aplikasi Zoom (sebagai klien) ke peladen (server) Zoom untuk menjalankan suatu tindakan tertentu, seperti memulai rapat, mengambil daftar kontak, atau mengirim pesan obrolan.

* Response
* pesan balasan yang dikirim oleh server aplikasi Anda kembali ke server Zoom sebagai tanggapan atas permintaan (request) atau pemberitahuan kejadian (webhook) dari Zoom
